# Abdur Razzak Sakib — Portfolio

A premium, recruiter-focused portfolio for **Abdur Razzak Sakib**, Full-Stack Web Developer. Built with Next.js (App Router), TypeScript, Tailwind CSS, Motion, and react-icons, using a black + lime green design system.

## Tech Stack

- Next.js 16 (App Router) + TypeScript (strict)
- Tailwind CSS v4
- Motion (`motion` package) for subtle animations, respecting `prefers-reduced-motion`
- react-icons (Simple Icons / VS Code sets) for real technology logos
- Lucide React for general UI icons
- Resend for server-side contact-form email delivery
- `next/font/google`: Plus Jakarta Sans (headings) + Inter (body)

## Action Required (before sharing)

1. **Profile photo** — `public/images/profile.png` currently holds your LinkedIn photo. Replace the file to update it.
2. **Project screenshots** — `public/projects/*.png` are real captures of the live sites (via thum.io). Replace them with your own screenshots if you prefer.
3. **Project detail pages** — `app/projects/[slug]/page.tsx` contains clearly-marked "editable placeholder" cards for purpose, development challenges, and possible improvements (projects that couldn't be verified from public sources). Fill those in with your own words.
4. **metadataBase** — update the deployment URL in `app/layout.tsx` after the first Vercel deploy.
5. **Resume content** — the resume text lives in `scripts/resume/resume.html`. Review the descriptions there (project features were taken from `lib/data/projects.ts`); edit and regenerate when your details change.

## Resume PDF

`public/resume.pdf` is generated by printing `scripts/resume/resume.html` with Headless Chromium
(Playwright) — selectable text, ATS-friendly, with clickable mailto/web link annotations. To
regenerate after editing the template:

```bash
npm i --no-save playwright && npx playwright install chromium
node scripts/generate-resume.mjs
node scripts/verify-resume.mjs   # optional: checks text layer + link annotations
```

These one-off tools are kept out of `package.json` on purpose so installs stay lean; `scripts/`
is excluded from ESLint.

## Contact Form

The **Say Hello** button opens an accessible modal form. The form posts to
`app/api/contact/route.ts`, which validates the input and sends it to your inbox with
[Resend](https://resend.com). API keys never reach the browser.

1. Create a Resend account and an API key (https://resend.com/api-keys).
2. Verify the domain you want to send from (https://resend.com/domains).
3. Copy `.env.example` to `.env.local` and fill in:

```bash
CONTACT_EMAIL=you@example.com
RESEND_API_KEY=re_your_api_key
RESEND_FROM_EMAIL="Portfolio Contact <contact@yourdomain.com>"
```

For a quick test, `RESEND_FROM_EMAIL="Portfolio Contact <onboarding@resend.dev>"`
works, but Resend only delivers that sender to the Resend account owner's address.
Until the variables are configured, the form shows an error and never reports a fake
success. The route also validates on the server, uses a honeypot field, and rate-limits
submissions per IP (best effort on serverless).

## Deployment (Vercel)

1. Push this repository to GitHub.
2. Import it at https://vercel.com/new (framework auto-detected: Next.js).
3. Add `CONTACT_EMAIL`, `RESEND_API_KEY`, and `RESEND_FROM_EMAIL` in the project's
   environment variables. No other secrets are required.
4. Update `metadataBase` in `app/layout.tsx` with the final production domain.
